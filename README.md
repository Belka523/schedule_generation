## Автоматический генератор расписания 

Проект для автоматического составления учебного расписания. Решает NP-трудную задачу комбинаторной оптимизации (Timetabling) с использованием гибридного подхода: **Жадного алгоритма** для создания начальной сетки и методов локального поиска (**Генетический алгоритм / Hill Climbing**) для устранения окон и балансировки нагрузки.

## Особенности проекта

* **Умная балансировка нагрузки**: Алгоритм равномерно распределяет пары по дням недели, избегая пустых дней и перегрузок.
* **Работа с потоками**: Поддержка проведения общих лекций для нескольких групп (потоков) одновременно.
* **Многофакторная оценка**: Учитываются окна у студентов, пересечения аудиторий, лимиты нагрузки преподавателей и соответствие специализаций.
* **Удобный экспорт**: Итоговое расписание форматируется в читаемый вид (с названиями дней, групп и предметов) и выгружается в Excel-файл.

## Структура проекта

* `main.py` — Точка входа в программу. Объединяет загрузку, генерацию, оптимизацию и сохранение результатов.
* `data_loader.py` — Модуль предобработки входных данных из Excel. Нормализует строки и создает быстрые индексы-словари.
* `generator.py` — Жадный алгоритм. Строит базовое расписание, используя эвристику для минимизации окон.
* `evaluator.py` — Модуль оценки. Вычисляет штрафы за окна, пустые дни, превышение лимитов пар и конфликты аудиторий.
* `optimizer.py` — Модуль оптимизации. Итеративно "докручивает" расписание, передвигая блоки занятий для минимизации штрафов.

## Установка и запуск

### Требования
Для работы проекта потребуется Python 3.8+ и следующие библиотеки:
```bash
numpy==2.4.4
openpyxl==3.1.5
pandas==3.0.2
```

### Запуск
1. Поместите файл с исходными данными (например, `test.xlsx`) в папку `data/`.
2. Запустите главный скрипт:
```bash
python main.py
```
3. После завершения работы скрипта, готовое расписание появится в файле `result_schedule.xlsx`.

## Формат входных данных
Проект ожидает на вход Excel-файл с 5 вкладками:
1. **Группы** (`group_id`, `group_name`)
2. **Преподаватели** (`teacher_id`, ФИО, специализация, дневной лимит, роль лектора/семинариста, группы)
3. **Слоты** (`slot_id`, день недели, порядковый номер пары, время начала и конца)
4. **Предметы** (`subject_id`, название, количество лекций, семинаров, лабораторных)
5. **Аудитории** (`room_id`, название, тип аудитории)

## Используемые алгоритмы
Проект демонстрирует применение гибридного подхода :
* **Жадный алгоритм**: Создает стартовое расписание и балансирует нагрузку в течении недели.
* **Генетический алгоритм**: Отвечает за поиск оптимального решения. Эволюционирует популяцию расписаний через элитизм и мутаций целыми смысловыми блоками.
* **Hill Climbing**: Применяется для точечной оптимизации особей в популяции. Алгоритм берет готовое расписание и делает множество сдвигов блоков занятий, сохраняя только те изменения, которые улучшают или не ухудшают результат. Это позволяет эффективно устранять мелкие коллизии и выходить из локальных минимумов.
